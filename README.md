# KisanMitra AI

AI Rural Decision Assistant

KisanMitra AI is a multilingual AI-powered platform
designed to help rural users access useful information
about agriculture, weather, water, markets and
government schemes.

## Main Features

- Gujarati AI Assistant
- Voice Interaction
- Weather Advisory
- Crop Assistant
- Water Advisory
- Market Information
- Government Scheme Assistant
- AI Agent
- RAG-based Knowledge System
- Smart Alerts
- Personalized User Dashboard

## Technology

Frontend: HTML, CSS, JavaScript
Backend: Python, FastAPI
Database: MySQL
AI: LLM + RAG + AI Agent
